# BE Agent Instructions

For changes under `alzan-be/`, prioritize shared skills under `.agents/skills/shared-*`.

Key defaults:
- Use `shared-nestjs-patterns` for NestJS module/controller/service work.
- Use `shared-api-design` for endpoint contracts, status codes, and error envelopes.
- Use `shared-backend-patterns` for architecture and service-layer patterns.
- Use `shared-supabase-postgres-best-practices` for DB-adjacent changes.
- Use `shared-database-schema` when validating data model assumptions.
- Use `shared-security-review` for auth, validation, secrets, and permission-sensitive changes.
- Use `shared-pnpm-quality-gate` before closing implementation tasks.
