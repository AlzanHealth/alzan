# Understand the Database Schema

## Workflow

1. Read the schema reference

- The full schema is located in `references/schema.md`.
- Read it to understand table structures, foreign keys, and constraints.

2. Answer user questions

- Use the schema context to explain data models.
- Write queries or explain relationships based on the actual DDL.

## Constraints

- Do not invent tables or columns not present in the reference.
- If the schema seems outdated, ask the user to run a schema dump update.
- **CRITICAL**: Do NOT manually edit the `database.types.ts` file under any circumstances. This file is auto-generated by running `pnpm run supabase:types` (or `supabase gen types`).

## References

- `references/schema.md`: The source of truth for the database structure (Markdown wrapped).
