# Backend Skill Routing

- Start with `shared-nestjs-expert-developer`.
- Pair with `shared-nestjs-patterns`, `shared-backend-patterns`, and `shared-api-design` for most backend implementation and refactors.
- Add `shared-supabase-expert-developer`, `shared-database-schema`, and `shared-supabase-postgres-best-practices` for schema, RLS, migration, or query work.
- Add `shared-security-review` for auth, secrets, validation, permissions, or untrusted input.
- Use documentation skills for backend or API docs.
- Any code change must finish with `shared-pnpm-quality-gate`.
