# Frontend Skill Routing

- Start with `fe-react-native-expert-developer`.
- Add only what the task needs:
  - `fe-mobile-ui-ux-direction` for UI/UX, navigation, or mobile visual work
  - `fe-react-native-best-practices` for lists, charts, blur, animation, scrolling, startup, or RN/Expo performance
  - `fe-react-component-performance` for render bottlenecks
  - `fe-manage-translations` for i18n and user-facing strings
  - `fe-upgrading-expo` for SDK or dependency upgrades
  - `fe-expo-cicd-workflows` for Expo/EAS workflow changes
- For visual exploration or premium polish, use `fe-design-taste-frontend`, `fe-emil-design-eng`, `fe-gpt-taste`, `fe-high-end-visual-design`, `fe-minimalist-ui`, or `fe-ui-ux-pro-max`, but ground final code in the RN/Expo skills above.
- Pull in shared skills only when the task truly needs them.
- Any code change must finish with `shared-pnpm-quality-gate`.
